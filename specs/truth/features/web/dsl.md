# 網頁共用 DSL

跨模組共用句型。模組專屬句型寫在 `{模組}/dsl.md`。

## 介面共通約定（所有 web 句型適用）

- 介面性質：瀏覽器 E2E（Playwright BDD）。桌機與手機尺寸各有一個 Playwright project；句型未特別說明時使用桌機尺寸。
- 場次資料：Arrange 一律透過 fixture 攔截場次快照請求並回傳 Given 表格建出的快照，不連官網、不依賴真實 `sessions.json`。
- 使用者狀態：Arrange 一律透過 state fixture 在頁面載入前預載（分層與層內順序、熱門、有空時段、每日上限、手動順序、搶票標記；兩人模式另有兩人顯示名稱與同伴資料），Gherkin 不出現儲存位置名稱；每個 Example 從乾淨瀏覽器環境開始。預載內容以保存格式 schema_version 3 寫入（見 `specs/truth/data/data-model.dbml`）。
- 層內順序（003）：`觀眾已標記影片層級如下：`、`同伴的分層如下：` 表格的列順序即該層內的先後（先列者在前）；選片頁以 `選片頁層內順序如下：` 驗證。
- 有空時段與不可看時段（003）：每人每天只有一份有空時段（分鐘精度，預設全天有空）。畫面與 DSL 稱「不可看時段」者，一律指有空時段的補集（整天有空的日期不列）；Given 的「不可看時段」是從有空時段扣掉該區間，同一日期可有多列、逐列累加。
- 個人模式與兩人模式：沒有預載同伴資料 = 個人模式，所有句型語意與 001 相同（沒有調整層內順序與小時格子時，行程與 001 相同；★ 不再凌駕層內順序，見 planner 的排程目標說明）；有同伴資料 = 兩人模式（各頁頂部顯示「兩人模式：{自己} ＋ {同伴}」；兩人各自以自己的片單、層內順序、有空時段、每日上限排程，行程每場標示「一起」或「{名字} 自己」）。同伴 Given 先寫成「待載入的同伴資料」，由 `觀眾已加入同伴，自己名稱為 …` 一次預載；`同伴傳來個人分享連結…`（兩人模式模組）則用同一份待載入同伴資料編成連結。
- 兩人模式的行程頁：預設篩選為「全部」；「只看自己」= 一起與{自己} 自己的場次；「只看同伴」= 一起與{同伴} 自己的場次。行程列的層級色塊顯示「視角」那個人的層級：視角預設為自己（全部、只看自己）；選「只看同伴」時視角為同伴；在「全部」中同伴自己看的列，一律顯示同伴的層級。兩人模式的搶票清單只列自己行程中的場次。
- 日期 `YYYY-MM-DD`、時間 `HH:MM`（24 小時制、Asia/Taipei），畫面上日期顯示為「11/15（日）」時，step 負責轉換比對。
- 不得在 DSL 主表出現 selector；定位細節留在 page object。
- 「場次」字串格式：`日期 開演`，影人出席場次後接 ` ★`，例如 `2026-11-15 14:00 ★`。

## Given 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `場次快照包含以下場次：` | 無 | 支援：`片名`（必填，字串）、`日期`（必填，日期）、`開演`（必填，時間）、`片長`（必填，整數分鐘）、`分級`（可選，字串）、`影廳`（必填，字串）、`標記`（可選，`★` `◆` `▲` `⊚` 可並列） | `分級`：未填時為 `普`。 | `使用 fixture`：場次快照 fixture。`Arrange 來源`：表格每列轉成快照中的影片與場次（影廳含「信義威秀」→ 台北信義威秀；含「TITAN」或「松仁威秀」→ 松仁威秀）。`頁面操作`：無。`等待條件`：無（尚未開啟頁面）。`回寫資料`：本 Example 的場次快照。 |
| `觀眾已標記影片層級如下：` | 無 | 支援：`片名`（必填，字串）、`層級`（必填，`必看` `想看` `有空再看`）、`熱門`（可選，`是` 或空白） | `熱門`：空白＝未標熱門。`層內順序`：同一層級內依表格列順序，先列者在前。 | `使用 fixture`：state fixture。`Arrange 來源`：表格寫入預載的使用者狀態（含層內名次：同層內依列順序 1、2、3…）；未列出的影片為未標記。`頁面操作`：無。`回寫資料`：預載使用者狀態。 |
| `觀眾已把以下影片標為不看：` | 無 | 支援：`片名`（必填，字串） | 無 | `使用 fixture`：state fixture。`Arrange 來源`：表格每列的影片 id 寫入預載使用者狀態的 `skipped_film_ids`（不看，與三個層級互斥；該片不得同時出現在 `觀眾已標記影片層級如下：`）。`頁面操作`：無。`回寫資料`：預載使用者狀態。 |
| `觀眾已設定不可看時段如下：` | 無 | 支援：`日期`（必填，日期）、`時段`（必填，`HH:MM–HH:MM` 或 `整天不可看`）；同一日期可有多列，逐列累加 | 無 | `使用 fixture`：state fixture。`Arrange 來源`：對每列，從預載有空時段（預設全天有空）扣掉該區間並合併相鄰區間；未列出的日期維持全天有空。`頁面操作`：無。`回寫資料`：預載使用者狀態。 |
| `觀眾已設定每日上限為 {上限} 部` | `上限`：整數；0 以上。 | 不支援 | 無 | `使用 fixture`：state fixture。`Arrange 來源`：把每日上限寫入預載使用者狀態。`頁面操作`：無。`回寫資料`：預載使用者狀態。 |
| `同伴的分層如下：` | 無 | 支援：`片名`（必填，字串；可以不在場次快照中）、`層級`（必填，`必看` `想看` `有空再看`）、`熱門`（可選，`是` 或空白） | `熱門`：空白＝未標熱門。`層內順序`：同一層級內依表格列順序，先列者在前。 | `使用 fixture`：state fixture。`Arrange 來源`：表格寫入「待載入的同伴資料」的分層、層內名次與熱門；尚未預載進頁面。`頁面操作`：無。`回寫資料`：待載入的同伴資料。 |
| `同伴已設定不可看時段如下：` | 無 | 支援：`日期`（必填，日期）、`時段`（必填，`HH:MM–HH:MM` 或 `整天不可看`）；同一日期可有多列，逐列累加 | 無 | `使用 fixture`：state fixture。`Arrange 來源`：對每列，從待載入同伴資料的有空時段扣掉該區間並合併相鄰區間。`頁面操作`：無。`回寫資料`：待載入的同伴資料。 |
| `同伴的每日上限已設為 {上限} 部` | `上限`：整數；0 以上。 | 不支援 | 未呼叫時，同伴不設上限。 | `使用 fixture`：state fixture。`Arrange 來源`：把每日上限寫入待載入同伴資料。`頁面操作`：無。`回寫資料`：待載入的同伴資料。 |
| `觀眾已排好行程` | 無 | 不支援 | 無 | `使用 fixture`：state fixture 與瀏覽器。`Arrange 來源`：以目前預載狀態開啟選片頁，按一次排行程並等行程頁出現（Arrange，不計入受測動作）。`等待條件`：行程頁的行程列表已顯示。`回寫資料`：目前頁面停在行程頁；行程已在畫面上。 |
| `觀眾已加入同伴，自己名稱為 "{自己}"、同伴名稱為 "{同伴}"` | `自己`：字串。<br>`同伴`：字串。 | 不支援 | 無 | `使用 fixture`：state fixture。`Arrange 來源`：把自己名稱、同伴名稱與目前的待載入同伴資料（沒有任何同伴 Given 時為空的同伴）預載進使用者狀態，使頁面一開啟就是兩人模式；自己的分層、時段、上限、搶票標記不動。`頁面操作`：無。`回寫資料`：預載使用者狀態；記下自己設定的基準快照（供「維持加入前的內容」比對）。 |
| `觀眾已排好行程並開啟搶票清單` | 無 | 不支援 | 無 | `使用 fixture`：state fixture 與瀏覽器。`Arrange 來源`：同「觀眾已排好行程」，再切到底部「搶票」分頁。`等待條件`：搶票清單的列已顯示。`回寫資料`：目前頁面停在搶票頁。 |
| `觀眾已把下列場次標記為搶到：` | 無 | 支援：`片名`（必填，字串）、`場次`（必填，字串；`日期 開演`） | 無 | `使用 fixture`：state fixture。`Arrange 來源`：把表格各列寫成預載搶票標記 got；頁面開啟時搶票清單已反映這些標記（若頁面已開啟則重新載入後回到搶票頁）。`等待條件`：搶票清單已依標記呈現。`回寫資料`：預載使用者狀態。 |

## Then 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `畫面顯示錯誤 "{錯誤}"` | `錯誤`：字串；使用者可讀的中文訊息。 | 不支援 | 無 | `必查`：`呈現結果`：目前畫面可見該訊息文字（完全相符）。`權威狀態`：使用者狀態未被這次失敗的操作改動（重新讀取保存內容與操作前相同）。`不該發生`：畫面不得出現技術錯誤碼或堆疊訊息。 |
| `畫面不需左右捲動即可讀完每筆影片、場次與備案` | 無 | 不支援 | 無 | `必查`：`呈現結果`：目前頁面的內容寬度不超過視窗寬度（無水平捲動），且每筆影片、排定場次與備案文字都在視窗內可見。`權威狀態`：目前使用手機尺寸 viewport（390 px 寬）。`不該發生`：任何列的場次或備案被截斷或藏在水平捲動外。 |
| `"{片名}" 顯示熱門標示` | `片名`：字串。 | 不支援 | 無 | `必查`：`呈現結果`：該片卡片顯示「熱門」標示，且卡片外觀（不必展開）上的熱門開關為開。`權威狀態`：使用者狀態中該片為熱門。`再讀確認`：重新載入後仍顯示。 |
| `時段頁顯示不可看時段如下：` | 無 | 支援：`日期`（必填，日期）、`時段`（必填，`HH:MM–HH:MM` 或 `整天不可看`）；同一日期可有多列 | 無 | `必查`：`呈現結果`：時段頁每個日期底下列出的時段與表格完全一致，且沒有表格以外的時段（列出的是有空時段的補集，由早到晚）。`權威狀態`：使用者狀態的有空時段取補集後與畫面一致。 |
| `時段頁 "{日期}" 的小時格子如下：` | `日期`：字串；`YYYY-MM-DD`。 | 支援：`小時`（必填，整數 0–23）、`狀態`（必填，`有空` `沒空` `部分沒空`）；表格未列出的小時一律比對為 `有空` | 無 | `必查`：`呈現結果`：時段頁該日期的 24 格小時格子，表格列出的每格狀態與表格一致，未列出的格子皆為有空，且三種狀態在畫面上有不同的外觀與文字（不靠顏色單獨表達）。`權威狀態`：每格狀態等於由使用者狀態的有空時段推導的結果（整小時全在有空內 = 有空；整小時全不在 = 沒空；其餘 = 部分沒空）。`再讀確認`：重新載入後仍一致。 |
| `選片頁層內順序如下：` | 無 | 支援：`層級`（必填，`必看` `想看` `有空再看`）、`順序`（必填，字串；片名以「、」連接，由前到後；該層沒有影片時不列） | 無 | `必查`：`呈現結果`：選片頁各層級內影片由前到後的順序與表格一致，且表格未列出的層級沒有影片。`權威狀態`：使用者狀態中各層的層內名次與畫面順序一致（同層內 1 起連續）。`再讀確認`：不重新載入也已更新；重新載入後仍一致。 |
| `時段頁顯示每日上限為 "{上限}"` | `上限`：字串；整數文字或 `不設上限`。 | 不支援 | 無 | `必查`：`呈現結果`：每日上限欄位顯示該值（空白欄位對應 `不設上限`）。`權威狀態`：使用者狀態的每日上限與畫面一致（空白＝null）。 |
| `搶票清單順序為 "{順序}"` | `順序`：字串；片名以「、」連接，由上而下。 | 不支援 | 無 | `必查`：`呈現結果`：搶票頁「未處理」區的列由上而下的片名與參數一致。`權威狀態`：使用者狀態的手動順序／自動順序與畫面一致。 |
| `"{片名}" 顯示為已搶到並移到已完成區` | `片名`：字串。 | 不支援 | 無 | `必查`：`呈現結果`：該片的列呈現「已搶到」狀態、「搶到」「沒搶到」按鈕不可再按，且位於已完成區而不在未處理區。`權威狀態`：使用者狀態中該場次為 got。 |
| `行程頁依日期顯示以下場次：` | 無 | 支援：`日期`（必填，日期）、`開演`（必填，時間）、`散場`（必填，時間）、`片名`（必填，字串）、`影廳`（必填，字串）、`層級`（必填，`必看` `想看` `有空再看`）、`參與者`（可選，`一起` 或 `{名字} 自己`，例如 `Fischer 自己`；兩人模式使用，無此欄時不比對） | 無 | `必查`：`呈現結果`：行程頁依日期分組的時間軸（兩人模式為目前篩選下的內容，預設全部），每個場次的開演–散場、片名、影廳（影城）、層級（定義見共通約定）與表格一致，有 `參與者` 欄時每列的「一起」或「{名字} 自己」標示也一致，順序為日期再開演時間，列數相同。`權威狀態`：畫面行程與目前使用者狀態（兩人模式含同伴資料）算出的行程及篩選相同。 |
