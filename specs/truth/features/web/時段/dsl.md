# 時段 DSL

這個模組的專屬句型。跨模組共用句型見 [`../dsl.md`](../dsl.md)（含 `時段頁 "{日期}" 的小時格子如下：`、`時段頁顯示不可看時段如下：`）。

時段頁以 24 格小時格子呈現每天的有空狀態（有空／沒空／部分沒空），並保留「不可看時段」輸入；兩者編輯同一份有空時段資料（FR-301～FR-303）。

日期選取規則：預設為單選模式，點日期 = 切換正在編輯的那一天。按「多選日期」進入多選模式後，點日期 = 加入／移除；離開多選模式只保留最後點的那一天。多選模式提供「同星期幾」捷徑。格子標題永遠寫出正在編輯的日期（單日「正在編輯：11/09（一）」；多日「正在編輯 2 天：11/09（一）、11/16（一）」）。單日點格子規則同 CL-302（有空 → 沒空、沒空 → 有空、部分沒空 → 沒空）；多選模式的格子顯示合併狀態（各日相同則同該狀態，不同則顯示「不一致」），點擊後所有被選日期設成同一狀態：全部沒空 → 全部有空，其餘 → 全部沒空。「加入不可看時段」與「整天不可看」套用到目前正在編輯的日期。日期格上有任何不可看時段的日期顯示「有設定」標示（圓點加無障礙文字）。

## When 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `觀眾在時段頁按下「下一步：選片」` | 無 | 不支援 | `起始畫面`：時段頁。 | `頁面操作`：開啟時段頁，按頁面底部的「下一步：選片」一次。`等待條件`：選片頁出現。`回寫資料`：無。 |
| `觀眾在時段頁對 "{日期}" 輸入不可看時段 "{時段}"` | `日期`：字串；`YYYY-MM-DD`。<br>`時段`：字串；`HH:MM–HH:MM`。 | 不支援 | `起始畫面`：時段頁。 | `頁面操作`：開啟時段頁，選取該日期，輸入起訖時間；只輸入、不按「套用」。`等待條件`：輸入驗證結果已呈現。`回寫資料`：無（尚未套用，使用者狀態不變）。 |
| `觀眾在時段頁選取以下日期並套用不可看時段 "{時段}"：` | `時段`：字串；`HH:MM–HH:MM`。 | 支援：`日期`（必填，日期；多列） | `起始畫面`：時段頁。 | `頁面操作`：開啟時段頁，開啟「多選日期」，依序點表格中的日期（加入選取），輸入起訖時間，按「套用」一次。`等待條件`：被選日期底下出現新時段。`回寫資料`：使用者狀態（不可看時段）。 |
| `觀眾在時段頁把 "{日期}" 整天設為不可看` | `日期`：字串；`YYYY-MM-DD`。 | 不支援 | `起始畫面`：時段頁。 | `頁面操作`：開啟時段頁，選取該日期，按「整天不可看」一次。`等待條件`：該日期顯示整天不可看。`回寫資料`：使用者狀態（不可看時段）。 |
| `觀眾在時段頁刪除 "{日期}" 的不可看時段` | `日期`：字串；`YYYY-MM-DD`。 | 不支援 | `起始畫面`：時段頁。 | `頁面操作`：開啟時段頁，在該日期已列出的時段上按刪除一次。`等待條件`：該時段從列表消失。`回寫資料`：使用者狀態（不可看時段）。 |
| `觀眾在時段頁切換編輯到 "{日期}"` | `日期`：字串；`YYYY-MM-DD`。 | 不支援 | `起始畫面`：時段頁（單選模式，預設）。 | `頁面操作`：開啟時段頁，點該日期的日期格恰好一次（單選模式下點日期 = 切換正在編輯的日期，不會保留前一天）。`等待條件`：該日期格為選取狀態、格子標題改寫為該日期。`回寫資料`：無。 |
| `觀眾在時段頁多選以下日期：` | 無 | 支援：`日期`（必填，日期；多列） | `起始畫面`：時段頁。 | `頁面操作`：開啟時段頁，按「多選日期」開啟多選模式，依序點表格中的日期（每點一次加入選取）。`等待條件`：表格日期皆為選取狀態。`回寫資料`：無。 |
| `觀眾在時段頁離開多選日期模式` | 無 | 不支援 | `起始畫面`：時段頁，已開啟多選模式。 | `頁面操作`：再按一次「多選日期」關閉多選模式。`等待條件`：「多選日期」不再為開啟狀態。`回寫資料`：無（離開後只保留最後點的那一天）。 |
| `觀眾在時段頁按下「同星期幾」` | 無 | 不支援 | `起始畫面`：時段頁，已開啟多選模式且至少選了一天。 | `頁面操作`：按「同星期幾」一次。`等待條件`：選取結果已更新。`回寫資料`：無（選取變成影展日期範圍內，與最後點的日期同星期幾的所有日期）。 |
| `觀眾在時段頁對已選日期點擊以下小時格子：` | 無 | 支援：`小時`（必填，整數 0–23；多列，依列順序各點一次） | `起始畫面`：時段頁，已開啟多選模式並已選日期。 | `頁面操作`：依序點多選格子區的各小時格子，每列恰好一次。`等待條件`：每次點擊後該格狀態已更新。`回寫資料`：使用者狀態（有空時段），規則同「選取以下日期並點擊 {小時} 點格子」的多選統一規則。 |
| `觀眾在時段頁查看 "{日期}" 的小時格子` | `日期`：字串；`YYYY-MM-DD`。 | 不支援 | `起始畫面`：時段頁。 | `頁面操作`：開啟時段頁，（若多選模式開啟則先關閉）選取該日期（只選取、不點格子）。`等待條件`：該日期的 24 格小時格子已呈現。`回寫資料`：無。 |
| `觀眾在時段頁點擊 "{日期}" 的 {小時} 點格子` | `日期`：字串；`YYYY-MM-DD`。<br>`小時`：整數；0–23。 | 不支援 | `起始畫面`：時段頁。 | `頁面操作`：開啟時段頁，（若多選模式開啟則先關閉）選取該日期，點該小時格子恰好一次。`等待條件`：該格狀態已更新。`回寫資料`：使用者狀態（有空時段）：有空 → 該整小時沒空；沒空 → 該整小時有空；部分沒空 → 該整小時沒空（FR-303）。 |
| `觀眾在時段頁選取以下日期並點擊 {小時} 點格子：` | `小時`：整數；0–23。 | 支援：`日期`（必填，日期；多列） | `起始畫面`：時段頁。 | `頁面操作`：開啟時段頁，開啟「多選日期」，依序點表格中的日期，點多選格子區的該小時格子恰好一次。`等待條件`：被選日期的該格狀態皆已更新。`回寫資料`：使用者狀態（有空時段）：多選統一規則——被選日期該小時若全部沒空，全部改為有空；其餘情況（全部有空、部分沒空、或各日不一致）全部改為沒空。 |
| `觀眾在時段頁輸入每日上限 "{上限}"` | `上限`：字串；整數文字或負數文字。 | 不支援 | `起始畫面`：時段頁。 | `頁面操作`：開啟時段頁，在每日上限欄位輸入該值並離開欄位（確認輸入）。`等待條件`：欄位驗證結果已呈現。`回寫資料`：輸入合法時為使用者狀態（每日上限）；不合法時不變。 |
| `觀眾在時段頁清空每日上限` | 無 | 不支援 | `起始畫面`：時段頁。 | `頁面操作`：開啟時段頁，清空每日上限欄位並離開欄位。`等待條件`：欄位顯示為空白。`回寫資料`：使用者狀態（每日上限＝null，即不設上限）。 |
| `觀眾開啟選片頁查看各片場次` | 無 | 不支援 | `展開`：展開所有已有場次的影片卡片。 | `頁面操作`：開啟選片頁並展開卡片。`等待條件`：場次列的可看狀態已呈現。`回寫資料`：無。 |

## Then 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `底部分頁順序為 "{順序}"` | `順序`：字串；分頁名稱以「、」連接，由左到右。 | 不支援 | 無 | `必查`：`呈現結果`：底部分頁列由左到右的名稱與順序一致。 |
| `畫面停在 "{頁面}" 頁` | `頁面`：字串；`時段` `選片` `行程` `搶票` `分享`。 | 不支援 | 無 | `必查`：`呈現結果`：該分頁在底部分頁列為目前頁（aria-current=page），頁首標題為該頁名稱。 |
| `套用按鈕停用` | 無 | 不支援 | 無 | `必查`：`呈現結果`：「套用」按鈕為停用狀態。`權威狀態`：使用者無法真的送出這次不合法的時段（嘗試點擊或按 Enter 後使用者狀態仍不變）。`不該發生`：不可看時段不得新增一筆。 |
| `時段頁沒有任何不可看時段` | 無 | 不支援 | 無 | `必查`：`呈現結果`：時段頁沒有列出任何不可看時段。`權威狀態`：使用者狀態的不可看時段為空。`再讀確認`：重新載入後仍為空。 |
| `時段頁每日上限欄位顯示輸入錯誤` | 無 | 不支援 | 無 | `必查`：`呈現結果`：欄位旁出現中文錯誤提示，說明每日上限只接受 0 以上整數。`權威狀態`：使用者狀態的每日上限維持輸入前的值。 |
| `選片頁的場次可看狀態如下：` | 無 | 支援：`片名`（必填，字串）、`日期`（必填，日期）、`開演`（必填，時間）、`可看`（必填，`可看` 或 `不可看`） | 無 | `必查`：`呈現結果`：每個場次列上「不可看」標示的有無與表格一致。`權威狀態`：與使用者狀態中的有空時段以分鐘推算相符（開演到散場每一分鐘都有空才可看）。 |
| `時段頁 "{日期}" 的 24 格皆為有空` | `日期`：字串；`YYYY-MM-DD`。 | 不支援 | 無 | `必查`：`呈現結果`：時段頁該日期的 24 格小時格子全部呈現為有空，且該日期底下沒有任何不可看時段列。`權威狀態`：使用者狀態中該日期沒有自訂的有空時段（全天有空，預設）。`再讀確認`：重新載入後仍是 24 格皆有空。 |
| `時段頁正在編輯 "{日期清單}"` | `日期清單`：字串；`YYYY-MM-DD` 以「、」連接，由早到晚。 | 不支援 | 無 | `必查`：`呈現結果`：格子標題寫出且只寫出這些日期（單日 `正在編輯：11/09（一）`；多日 `正在編輯 N 天：11/09（一）、11/16（一）`），且只有這些日期格為選取狀態。`權威狀態`：「加入不可看時段」的說明文字為 `套用到已選的 N 天`，N 等於日期數。 |
| `時段頁多選編輯中的小時格子如下：` | 無 | 支援：`小時`（必填，整數 0–23）、`狀態`（必填，`有空` `沒空` `部分沒空` `不一致`）；表格未列出的小時不比對 | 無 | `必查`：`呈現結果`：多選格子區中表格列出的每格合併狀態與文字一致；各日期狀態不同的格子顯示「不一致」，且外觀與其他狀態不同（不靠顏色單獨表達）。`權威狀態`：合併狀態由各被選日期該小時的狀態推導（全部相同 = 該狀態；否則 = 不一致）。 |
| `時段頁日期 "{日期}" 顯示有設定標示` | `日期`：字串；`YYYY-MM-DD`。 | 不支援 | 無 | `必查`：`呈現結果`：該日期格上有圓點標示與無障礙文字「有設定」。`權威狀態`：使用者狀態的有空時段中該日期有自訂（不是全天有空）。 |
| `時段頁日期 "{日期}" 不顯示有設定標示` | `日期`：字串；`YYYY-MM-DD`。 | 不支援 | 無 | `必查`：`呈現結果`：該日期格上沒有「有設定」標示。`權威狀態`：使用者狀態的有空時段中該日期全天有空（預設）。 |
