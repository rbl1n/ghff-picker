# 選片 DSL

這個模組的專屬句型。跨模組共用句型見 [`../dsl.md`](../dsl.md)（含 `選片頁層內順序如下：`）。

選片頁提供「層內順序」檢視：依必看、想看、有空再看三層列出已標記的影片，每部片左側有拖曳把手 ⋮⋮（`tier-drag-handle`，觸控目標至少 44px，只有把手會啟動拖曳，頁面照常可捲動）（FR-305）：可拖到同層任一位置，也可拖進另一層（改層並插在放下的位置，兩層名次重編為 1 起連續；熱門保留）；空的層顯示放置區「拖到這裡」；把手可用鍵盤操作（Tab 聚焦、空白鍵拿起、上下方向鍵移動、空白鍵放下）。滑鼠、觸控、鍵盤三種都支援，拖到畫面邊緣時頁面自動捲動。每列另有一排層級切換（必看｜想看｜有空｜不看，目前層級醒目，每鍵至少 44px，窄螢幕在列的第二行），點一下即改層：影片排在目標層最後、原層名次遞補；點不看則從層內順序移除（同卡片的不看）。不再有「上移」「下移」按鈕；個人與兩人模式都是調整自己的順序。

影片的手冊片號（`catalog_no`，紙本手冊目次表頁碼）以灰色等寬小字顯示在片名前（`data-testid=catalog-no`，片名文字本身不含片號）；選片頁與所有「影片順序」依手冊順序（片號由小到大、沒有片號者在最後）。

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |

## 影片備註

每部片可寫一則只有自己看得到的備註（`film_notes`，film_id → 文字）：顯示在選片卡片片名下方（灰色小字，預設最多兩行，點擊展開全文），「備註」／「編輯備註」按鈕開啟輸入框，按「確定」或離開輸入框時儲存，清空即刪除。備註存在本機，且包含在分享連結裡（換裝置用「取代我的設定」時一併帶過去）；當作同伴加入時，同伴連結裡的備註一律丟棄，不存也不顯示。
