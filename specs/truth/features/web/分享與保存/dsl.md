# 分享與保存 DSL

這個模組的專屬句型。跨模組共用句型見 [`../dsl.md`](../dsl.md)。

連結種類：個人模式產生的是「個人分享連結」，兩人模式產生的是「合併結果連結」。開啟個人分享連結的對話為「這是「{名稱}」的選片。」加上說明「要用這份設定取代此裝置的設定嗎？也可以當作同伴加入，保留你自己的設定。」，選項為「當作同伴加入」「取代我的設定」「取消」；開啟合併結果連結的對話為「這是「{自己} ＋ {同伴}」的合併結果。」加上說明「開啟後會取代此裝置目前的設定。」，選項只有「取代並開啟」「取消」。

003 起保存與分享連結的格式為 schema_version 3：不可看時段改存為有空時段、影片分層帶層內名次（見 `specs/truth/data/data-model.dbml`）。讀取接受 1、2、3（1、2 依遷移規則轉成 3：不可看時段從全天有空相減，層內順序依場次表的影片順序初始化），寫入一律為 3，高於 3 視為損毀連結／版本不符。

兩台裝置的建模：「電腦」是桌機尺寸的瀏覽器 context，「手機」是手機尺寸、乾淨環境（沒有任何預載狀態）的另一個瀏覽器 context；兩者共用同一份場次快照 fixture。

## Given 句型

| --- | --- | --- | --- | --- |
| `觀眾已把搶票清單順序手動調整為 "{順序}"` | `順序`：字串；片名以「、」連接。 | 不支援 | 無 | `使用 fixture`：state fixture。`Arrange 來源`：把該順序寫入預載使用者狀態的手動順序。`頁面操作`：無。`回寫資料`：預載使用者狀態。 |
| `電腦上已產生分享連結` | 無 | 不支援 | 無 | `使用 fixture`：桌機 context 與手機 context。`Arrange 來源`：電腦為個人模式（沒有同伴），已排好行程並開啟搶票清單，接著開啟分享畫面並讀出「複製連結」的連結文字，存為後續手機要開的網址（連結種類為個人分享連結）；同時記下電腦搶票清單的順序、排定場次、備案場次作為比對基準。`等待條件`：分享畫面顯示連結。`回寫資料`：分享連結與電腦清單快照。 |
| `手機已用分享連結匯入設定` | 無 | 不支援 | 無 | `使用 fixture`：手機 context。`Arrange 來源`：手機開啟個人分享連結並按「取代我的設定」（Arrange；個人連結的對話另有「當作同伴加入」，此句不選它）。`等待條件`：手機進入搶票頁。`回寫資料`：手機本機保存已含匯入的設定。 |
| `電腦上已產生合併結果連結` | 無 | 不支援 | 無 | `使用 fixture`：桌機 context 與手機 context。`Arrange 來源`：電腦已是兩人模式、已排好行程並開啟搶票清單（含 Given 設定的手動順序與搶票標記），接著開啟分享畫面並讀出「複製連結」的連結文字，存為後續手機要開的網址；同時記下電腦的行程、搶票清單（順序、排定場次、備案場次、張數）與兩人名稱作為比對基準。`等待條件`：分享畫面顯示連結。`回寫資料`：分享連結與電腦行程／清單快照。 |
| `手機已用合併結果連結取代並開啟` | 無 | 不支援 | 無 | `使用 fixture`：手機 context。`Arrange 來源`：手機開啟合併結果連結並按「取代並開啟」（Arrange）。`等待條件`：手機進入兩人模式且搶票清單已顯示。`回寫資料`：手機本機保存已含合併結果。 |
| `裝置上保存的是 001 版本格式的設定，分層如下：` | 無 | 支援：`片名`（必填，字串）、`層級`（必填，`必看` `想看` `有空再看`） | 無 | `使用 fixture`：state fixture。`Arrange 來源`：把表格寫成 001 版本格式的保存內容（schema_version 為 1，沒有自己名稱、沒有同伴資料）預載進本機保存；不經 002 的寫入程式。`頁面操作`：無。`回寫資料`：預載使用者狀態（v1 格式）。 |
| `手機收到 001 版本格式的個人分享連結` | 無 | 不支援 | 無 | `使用 fixture`：手機 context 與分享連結編碼 helper。`Arrange 來源`：以 001 版本的編碼方式（內容為 schema_version 1 的使用者狀態、沒有連結種類欄位）編成分享連結，存為後續手機要開的網址。`頁面操作`：無。`回寫資料`：分享連結。 |
| `裝置上保存的是 002 版本格式的設定，不可看時段如下：` | 無 | 支援：`日期`（必填，日期）、`時段`（必填，`HH:MM–HH:MM` 或 `整天不可看`）；同一日期可有多列 | 無 | `使用 fixture`：state fixture。`Arrange 來源`：把表格寫成 002 版本格式的保存內容（schema_version 為 2、不可看時段為獨立區間清單、沒有有空時段與層內名次）預載進本機保存；不經 003 的寫入程式。`頁面操作`：無。`回寫資料`：預載使用者狀態（v2 格式）。 |
| `手機收到 001 版本格式的個人分享連結，不可看時段如下：` | 無 | 支援：`日期`（必填，日期）、`時段`（必填，`HH:MM–HH:MM` 或 `整天不可看`）；同一日期可有多列 | 無 | `使用 fixture`：手機 context 與分享連結編碼 helper。`Arrange 來源`：以 001 版本的編碼方式（schema_version 1、不可看時段為獨立區間清單、沒有連結種類欄位）編成含這些不可看時段的分享連結，存為後續手機要開的網址。`頁面操作`：無。`回寫資料`：分享連結。 |
| `分享連結的版本高於本工具支援的版本` | 無 | 不支援 | 無 | `使用 fixture`：手機 context 與分享連結編碼 helper。`Arrange 來源`：把分享連結內容編成 schema_version 為 4 的版本（內容結構完整但版本高於 3）。`頁面操作`：無。`回寫資料`：版本不符的分享連結。 |
| `分享連結內容已損毀` | 無 | 不支援 | 無 | `使用 fixture`：手機 context。`Arrange 來源`：把分享連結的編碼內容截斷或改寫為無法解碼。`回寫資料`：損毀的分享連結。 |

## When 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `觀眾關閉工具後重新開啟` | 無 | 不支援 | 無 | `頁面操作`：關閉頁面並在同一個瀏覽器環境（保留本機保存）重新開啟網站首頁一次。`等待條件`：首頁載入完成。`回寫資料`：無。`不必查`：不模擬清除站台資料。 |
| `觀眾在手機上關閉工具後重新開啟` | 無 | 不支援 | 無 | `頁面操作`：關閉手機 context 的頁面，在同一手機環境重新開啟網站首頁一次。`等待條件`：首頁載入完成。`回寫資料`：無。 |
| `觀眾在電腦上開啟分享畫面` | 無 | 不支援 | 無 | `頁面操作`：在電腦搶票清單頁點右上角「分享」一次。`等待條件`：分享畫面載入。`回寫資料`：無。 |
| `觀眾用手機開啟該分享連結` | 無 | 不支援 | 無 | `頁面操作`：手機 context 開啟先前取得（或損毀）的分享連結一次。`等待條件`：出現確認對話或錯誤畫面。`回寫資料`：無（尚未確認，手機本機保存不變）。 |
| `觀眾用手機開啟該分享連結並選擇取代並開啟` | 無 | 不支援 | 無 | `頁面操作`：手機 context 開啟合併結果連結，在合併結果對話按「取代並開啟」，視為一次連續操作。`等待條件`：手機進入兩人模式且搶票清單已顯示。`回寫資料`：手機本機保存（合併結果：兩人資料、名稱、手動順序、搶票標記）。 |
| `觀眾用手機開啟該分享連結並確認取代` | 無 | 不支援 | 無 | `頁面操作`：手機 context 開啟個人分享連結，在個人連結對話按「取代我的設定」（取代鈕名稱含「取代」），視為一次連續操作；此句不選「當作同伴加入」。`等待條件`：手機進入搶票頁且清單已顯示。`回寫資料`：手機本機保存（匯入的設定）。 |

## Then 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `選片頁顯示影片層級如下：` | 無 | 支援：`片名`（必填，字串）、`層級`（必填，`必看` `想看` `有空再看` `未標記` `不看`） | 無 | `必查`：`呈現結果`：開啟選片頁，每部片的層級外觀與表格一致（未標記＝無層級色塊；`不看` 的片在「不看」篩選中呈不看啟用、三個層級都未啟用，且不出現在預設的「全部」清單）。`權威狀態`：本機保存的分層與 `skipped_film_ids` 與畫面一致。`再讀確認`：再重新載入一次仍一致。 |
| `分享畫面顯示 QR code 與「複製連結」` | 無 | 不支援 | 無 | `必查`：`呈現結果`：分享畫面有 QR code 影像與可操作的「複製連結」按鈕，並有一行說明如何用手機掃描打開同一份清單。`權威狀態`：QR code 編碼的網址與「複製連結」的網址相同。 |
| `手機畫面顯示確認 "{確認}"` | `確認`：字串；如 `要用這份設定取代此裝置的設定嗎？`。 | 不支援 | 無 | `必查`：`呈現結果`：手機畫面出現的個人分享連結對話，說明文字包含該確認文字，並有取代與取消選項（個人連結另有「當作同伴加入」，其選項集合由 `手機畫面的分享連結選項為` 驗證）。`權威狀態`：在使用者確認之前，手機本機保存沒有被改寫。 |
| `手機的選片頁 "{篩選}" 篩選列出的影片如下：` | `篩選`：字串；`全部` `已標記` `未標記` `不看`。 | 支援：`片名`（必填，字串） | 無 | `必查`：`呈現結果`：手機選片頁切到該篩選後，影片卡片與表格逐列一致。`權威狀態`：手機本機保存的 `skipped_film_ids` 與電腦一致。`再讀確認`：手機重新載入後仍一致。 |
| `手機的搶票清單與電腦完全相同（順序、排定場次、備案場次）` | 無 | 不支援 | 無 | `必查`：`呈現結果`：手機搶票頁每一列的順序、片名、排定場次與備案場次，與 Given 記下的電腦清單快照逐列一致；兩人模式時另逐列比對各列張數（一起看「買 2 張」、自己看「買 1 張」）且清單只含分給自己的場次（我的順序）。`權威狀態`：手機本機保存的分層、時段、熱門、手動順序與電腦一致。`再讀確認`：手機重新載入後仍一致。 |
| `手機畫面的分享連結選項為 "{選項}"` | `選項`：字串；選項名稱以「、」連接，如 `當作同伴加入、取代我的設定、取消` 或 `取代並開啟、取消`。 | 不支援 | 無 | `必查`：`呈現結果`：手機對話的按鈕集合與參數完全一致（不多不少，順序不比對）。`權威狀態`：在使用者選擇之前，手機本機保存沒有被改寫。`不該發生`：合併結果連結的對話不得有「當作同伴加入」。 |
| `分享畫面標示為合併結果連結，並提供 QR code 與「複製連結」` | 無 | 不支援 | 無 | `必查`：`呈現結果`：分享畫面可見「合併結果連結」標示、QR code 影像與可操作的「複製連結」按鈕。`權威狀態`：QR code 與「複製連結」的網址相同，且網址內容的種類為合併結果（含兩人資料與姓名）。 |
| `手機畫面顯示合併結果確認 "{確認}"` | `確認`：字串；如 `這是「Fischer ＋ 小美」的合併結果。`。 | 不支援 | 無 | `必查`：`呈現結果`：手機對話可見該確認文字與說明「開啟後會取代此裝置目前的設定。」。`權威狀態`：在使用者確認之前，手機本機保存沒有被改寫。 |
| `手機進入兩人模式並顯示 "{橫幅}"` | `橫幅`：字串；如 `兩人模式：Fischer ＋ 小美`。 | 不支援 | 無 | `必查`：`呈現結果`：手機畫面頂部橫幅文字完全等於參數，並有「移除同伴」按鈕。`權威狀態`：手機本機保存的自己名稱、同伴名稱、同伴的分層、不可看時段與每日上限，與電腦一致。`再讀確認`：手機重新載入後仍顯示。 |
| `手機的行程與電腦完全相同` | 無 | 不支援 | 無 | `必查`：`呈現結果`：手機行程頁（預設篩選「全部」）每個場次的日期、開演–散場、片名、影廳、層級與「一起」「{名字} 自己」標示，與 Given 記下的電腦行程快照逐列一致。`權威狀態`：手機本機保存的自己分層、時段、上限、手動順序、搶票標記與電腦一致。`再讀確認`：手機重新載入後仍一致。 |
| `重新開啟後仍為兩人模式並顯示 "{橫幅}"` | `橫幅`：字串；如 `兩人模式：Fischer ＋ 小美`。 | 不支援 | 無 | `必查`：`呈現結果`：重新開啟後頂部橫幅文字等於參數。`權威狀態`：本機保存的同伴分層、不可看時段、每日上限與兩人名稱，與關閉前一致。 |
| `手機的時段頁顯示不可看時段如下：` | 無 | 支援：`日期`（必填，日期）、`時段`（必填，`HH:MM–HH:MM` 或 `整天不可看`）；同一日期可有多列 | 無 | `必查`：`呈現結果`：手機時段頁每個日期底下列出的不可看時段（有空時段的補集）與表格完全一致，沒有表格以外的時段。`權威狀態`：手機本機保存以 schema_version 3 寫入，其有空時段取補集後與畫面一致。`再讀確認`：手機重新載入後仍一致。 |
| `手機的選片頁層內順序如下：` | 無 | 支援：`層級`（必填，`必看` `想看` `有空再看`）、`順序`（必填，字串；片名以「、」連接，由前到後） | 無 | `必查`：`呈現結果`：手機選片頁各層級內影片由前到後的順序與表格一致。`權威狀態`：手機本機保存的層內名次與電腦一致。`再讀確認`：手機重新載入後仍一致。 |

## 官方連結

分享頁底部有「官方連結」區（`data-testid=official-links`），每個連結 `target=_blank`、`rel` 含 `noopener`；網址取自官網場次頁與購票資訊頁。

### When

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `觀眾打開分享頁` | 無 | 不支援 | 無 | `頁面操作`：以目前 fixture 開啟網站並進入分享頁。`等待條件`：官方連結區可見。`回寫資料`：無。 |

### Then

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `分享頁的官方連結如下：` | 無 | 支援：`名稱`（必填，字串）、`網址`（必填，字串） | 無 | `必查`：`呈現結果`：官方連結區的連結（依畫面順序）名稱與網址和表格逐列一致，列數相同，且都在新分頁開啟（`target=_blank`、`rel` 含 `noopener`）。`不該發生`：不連網驗證。 |
