# 分享與保存 DSL

這個模組的專屬句型。跨模組共用句型見 [`../dsl.md`](../dsl.md)。

兩台裝置的建模：「電腦」是桌機尺寸的瀏覽器 context，「手機」是手機尺寸、乾淨環境（沒有任何預載狀態）的另一個瀏覽器 context；兩者共用同一份場次快照 fixture。

## Given 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `觀眾已排好行程` | 無 | 不支援 | 無 | `使用 fixture`：state fixture 與瀏覽器。`Arrange 來源`：以目前預載狀態開啟選片頁，按一次排行程並等行程頁出現（Arrange，不計入受測動作）。`等待條件`：行程頁的行程列表已顯示。`回寫資料`：目前頁面停在行程頁；行程已在畫面上。 |
| `觀眾已把搶票清單順序手動調整為 "{順序}"` | `順序`：字串；片名以「、」連接。 | 不支援 | 無 | `使用 fixture`：state fixture。`Arrange 來源`：把該順序寫入預載使用者狀態的手動順序。`頁面操作`：無。`回寫資料`：預載使用者狀態。 |
| `電腦上已產生分享連結` | 無 | 不支援 | 無 | `使用 fixture`：桌機 context 與手機 context。`Arrange 來源`：電腦已排好行程並開啟搶票清單，接著開啟分享畫面並讀出「複製連結」的連結文字，存為後續手機要開的網址；同時記下電腦搶票清單的順序、排定場次、備案場次作為比對基準。`等待條件`：分享畫面顯示連結。`回寫資料`：分享連結與電腦清單快照。 |
| `手機已用分享連結匯入設定` | 無 | 不支援 | 無 | `使用 fixture`：手機 context。`Arrange 來源`：手機開啟分享連結並按確認取代（Arrange）。`等待條件`：手機進入搶票頁。`回寫資料`：手機本機保存已含匯入的設定。 |
| `分享連結內容已損毀` | 無 | 不支援 | 無 | `使用 fixture`：手機 context。`Arrange 來源`：把分享連結的編碼內容截斷或改寫為無法解碼。`回寫資料`：損毀的分享連結。 |

## When 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `觀眾關閉工具後重新開啟` | 無 | 不支援 | 無 | `頁面操作`：關閉頁面並在同一個瀏覽器環境（保留本機保存）重新開啟網站首頁一次。`等待條件`：首頁載入完成。`回寫資料`：無。`不必查`：不模擬清除站台資料。 |
| `觀眾在手機上關閉工具後重新開啟` | 無 | 不支援 | 無 | `頁面操作`：關閉手機 context 的頁面，在同一手機環境重新開啟網站首頁一次。`等待條件`：首頁載入完成。`回寫資料`：無。 |
| `觀眾在電腦上開啟分享畫面` | 無 | 不支援 | 無 | `頁面操作`：在電腦搶票清單頁點右上角「分享」一次。`等待條件`：分享畫面載入。`回寫資料`：無。 |
| `觀眾用手機開啟該分享連結` | 無 | 不支援 | 無 | `頁面操作`：手機 context 開啟先前取得（或損毀）的分享連結一次。`等待條件`：出現確認對話或錯誤畫面。`回寫資料`：無（尚未確認，手機本機保存不變）。 |
| `觀眾用手機開啟該分享連結並確認取代` | 無 | 不支援 | 無 | `頁面操作`：手機 context 開啟分享連結，在「要用這份設定取代此裝置的設定嗎？」確認對話按確認，視為一次連續操作。`等待條件`：手機進入搶票頁且清單已顯示。`回寫資料`：手機本機保存（匯入的設定）。 |

## Then 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | Playwright BDD 實作語意 |
| --- | --- | --- | --- | --- |
| `選片頁顯示影片層級如下：` | 無 | 支援：`片名`（必填，字串）、`層級`（必填，`必看` `想看` `有空再看` `未標記`） | 無 | `必查`：`呈現結果`：開啟選片頁，每部片的層級外觀與表格一致（未標記＝無層級色塊）。`權威狀態`：本機保存的分層與畫面一致。`再讀確認`：再重新載入一次仍一致。 |
| `分享畫面顯示 QR code 與「複製連結」` | 無 | 不支援 | 無 | `必查`：`呈現結果`：分享畫面有 QR code 影像與可操作的「複製連結」按鈕，並有一行說明如何用手機掃描打開同一份清單。`權威狀態`：QR code 編碼的網址與「複製連結」的網址相同。 |
| `手機畫面顯示確認 "{確認}"` | `確認`：字串；如 `要用這份設定取代此裝置的設定嗎？`。 | 不支援 | 無 | `必查`：`呈現結果`：手機畫面出現該確認對話文字及確認、取消選項。`權威狀態`：在使用者確認之前，手機本機保存沒有被改寫。 |
| `手機的搶票清單與電腦完全相同（順序、排定場次、備案場次）` | 無 | 不支援 | 無 | `必查`：`呈現結果`：手機搶票頁每一列的順序、片名、排定場次與備案場次，與 Given 記下的電腦清單快照逐列一致。`權威狀態`：手機本機保存的分層、時段、熱門、手動順序與電腦一致。`再讀確認`：手機重新載入後仍一致。 |
