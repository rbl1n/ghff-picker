# 兩人合併 DSL

這個模組的專屬句型。跨模組共用句型見 [`../dsl.md`](../dsl.md)。同伴資料的 Given 句型（`同伴的分層如下：`、`同伴已設定不可看時段如下：`、`同伴的每日上限已設為 {上限} 部`）在介面根，因為搶票順序與備案、搶票切換模組也用。

> 模組名稱沿用 002 的「兩人合併」以保留落點路徑；003 起語意是「兩人各自片單的同時排程」，不再有「合併層級／合併時段／合併上限」。002 的合併規則已刪除。

## 兩人排程定義（本模組所有句型共用的判定基準）

- 每人各自：分層、層內排序（同層列順序）、有空時段、每日上限、相容判定。每人的可看、相容、每日上限只約束自己的行程；每人每部片最多一場。
- 只有一人分層（或同伴標了但場次快照沒有）的影片，只可能排入該人的行程。
- 參與者：同一場次兩人都排入 = `一起`；只有觀眾排入 = `觀眾自己`；只有同伴排入 = `同伴自己`。
- 兩人排程目標（依序比較，前一項較大者勝；CL-301）：
  1. 兩人必看數合計　2. 兩人想看數合計　3. 兩人有空再看數合計
  4. 層內排序：觀眾與同伴各自依個人目標第 4 項比較，兩人皆不劣且至少一人較佳者勝；否則視為相同
  5. 一起看的場次數
  6. 兩人 ★ 場次數合計
- 推導（可用窮舉驗證）：第 1～4 項等同「兩人各自達到個人最佳」；兩人目標的最佳解 = 在兩人各自都是個人最佳的組合中，一起看場次最多者，再比 ★ 合計；仍同分則固定為場次較早者。
- 世界沒有同伴資料時為個人模式，本模組的 Then 句型不適用。

## Then 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | StepDef 實作語意 |
| --- | --- | --- | --- | --- |
| `兩人行程依日期排列如下：` | 無 | 支援：`日期`（必填，日期）、`開演`（必填，時間）、`片名`（必填，字串）、`參與者`（必填，`一起`、`觀眾自己`、`同伴自己`） | 無 | `必查`：`呈現結果`：兩人行程的列數、順序與每列欄位和表格完全一致；順序依日期、開演時間，同一開演時間依 `一起`、`觀眾自己`、`同伴自己`，再依影片在場次表中首次出現的順序。`權威狀態`：觀眾自己的行程等於參與者為 `一起` 或 `觀眾自己` 的列，同伴的行程等於 `一起` 或 `同伴自己` 的列；每人每部片至多一列；`一起` 的場次對兩人都可看、都相容。`不該發生`：兩人行程不得有表格以外的場次；同一場次不得同時標 `觀眾自己` 與 `同伴自己`。 |
| `兩人行程的排程目標不劣於窮舉所有可行組合` | 無 | 不支援 | 無 | `必查`：`呈現結果`：以窮舉列出所有可行的兩人組合（每人每片至多一場、各自兩兩相容、各自可看、各自符合自己的每日上限；兩人排入同一場次即為一起），依本檔「兩人排程目標」第 1～6 項比較；找不到任何組合在第 1～3 項字典序較大、或前者相同而第 4 項較佳、或前四項相同而一起看場次數較多、或再相同而 ★ 合計較多。`權威狀態`：行程本身符合每人的限制。`不該發生`：存在更好的組合。 |
| `雙方原始設定與排程前相同` | 無 | 不支援 | 無 | `必查`：`呈現結果`：自己的分層與層內排序、熱門、有空時段、每日上限、手動順序、搶票標記，以及同伴資料，逐項等於 Given 完成時記下的快照。`權威狀態`：排程沒有寫入任何使用者狀態或同伴資料。`不該發生`：不得把同伴的分層或時段寫進自己的使用者狀態。 |
