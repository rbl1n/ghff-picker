# 功能規格：每部片的場次偏好（優先／只看這場）與兩人取捨（P3）

**功能分支**: `005-ghff-session-preference`

**建立日期**: 2026-10-25

**狀態**: 草稿

**輸入**: 使用者描述：「同一部片有好幾場時，我可以在選片頁的場次列上標記『優先』或『只看這場』；排程盡量照我的偏好，兩個人一起看時，如果為了一起看犧牲了我的優先場，要讓我看到取捨並自己決定。」例：理性與感性（手冊 239）有 11/10、11/15、11/20 三場，使用者偏好 11/20。

與既有 plan 的關係：001～004 已上線。本 plan 在「選場次」這一層加偏好：個人排程目標多一項、兩人排程目標多一項、行程頁新增「取捨」卡片。不改變分層、層內排序、有空時段、搶票分工的任何既有規則；沒有任何場次標記時，行為與 004 完全相同。

Clarify 拍板（2026-10-25，使用者確認）：

- **CL-501**：選片卡片展開的場次列，每場可標「優先」或「只看這場」（或不標）；同一部片可有多場同一種標記。標記屬於個人（`UserState.session_marks`，選填，schema 仍為 3），包含在分享連結，當作同伴加入時一併帶入 `PartnerData`（同伴的標記用於排程，不是私人資料）。
- **CL-502**：「只看這場」是硬限制：一部片只要有任何「只看」場次，該人對這部片的候選場次就只有那些場次；排不進去時該片未排入，原因為「指定場次都排不進去」，必看片照其他原因的方式列在未排入清單。
- **CL-503**：「優先」是軟偏好，絕不犧牲任何一部片。個人目標順序：層級數 → 層內名次 → **排在優先場的影片數（越多越好）** → ★。兩人模式：各人個人最佳（層級數、層內名次）→ 一起看場次數 → **優先場影片數（兩人合計）** → ★；即預設「一起看」勝過優先場。
- **CL-504**：兩人模式下，若某人的優先場因「一起看」而沒被採用（強制排那個優先場會改變一起看／各自看的結果），行程頁對該片顯示「取捨」卡片，以實際重跑排程比較兩個選項：A「一起看 {日期時間}」（目前預設，代價 = 放棄你的優先場）、B「看你的優先場 {日期時間}」（把該人的該片鎖定在優先場，重算後顯示兩人相對 A 的具體差異）。使用者可按鈕選 B，決定依「片 × 人」保存（`pinned_choices`），效果等同該片「只看這場」（限定在優先場）；「改回一起看」可還原；決定隨分享連結帶走。兩個選項實際沒有差異時不顯示卡片。每個衝突片重跑一次排程，數量少、有上限。

## 範圍

本版做：場次偏好標記（選片頁）、排程目標新增第 3.5 項、未排入原因、搶票備案的偏好、兩人取捨卡片與決定、分享與保存、行程列「優先場」小標。

本版不做：優先的強弱分級、整部片層級以外的權重、對「只看這場」的取捨卡片（硬限制，沒有取捨）、個人模式的取捨卡片（沒有衝突來源）。

## 使用者情境與測試 *(必填)*

### 使用者故事 1 - 標記哪一場是我想看的 (Priority: P1)

作為已經知道某部片想看哪一天的人，我希望在選片頁的場次列上直接標「優先」或「只看這場」，排程就盡量照我的偏好排，以便不用每次排完再手動換場次。

**為何為此優先級**: 這是 P3 的核心；沒有標記就沒有取捨。

**獨立驗證方式**: 以下例資料標記後排行程，結果與表格一致。

**舉例說明**（場次取自官網資料，備註為虛構）：

理性與感性（手冊 239）：11/10 21:20、11/15 11:00、11/20 10:50，片長 136 分鐘，皆在 TITAN。使用者想看，偏好 11/20。

| 情境 | 標記 | 其他條件 | 排定 |
| --- | --- | --- | --- |
| 優先沒有代價 | 11/20 優先 | 無衝突 | 11/20 10:50（沒標時會是最早的 11/10 21:20） |
| 優先會犧牲別部片 | 11/20 優先 | 必看〈北方〉只有 11/20 12:00 一場，與 11/20 10:50 衝堂 | 北方 11/20 12:00、理性與感性 11/10 21:20（優先不犧牲任何一部片） |
| 只看這場 | 11/20 只看 | 無衝突 | 11/20 10:50 |
| 只看但排不進去 | 11/20 只看 | 必看，同日有排在前面的必看〈北方〉12:00 衝堂 | 理性與感性未排入，原因「指定場次都排不進去」 |

**驗收情境**:

1. **Given** 理性與感性想看、11/20 標優先且無衝突，**When** 排程，**Then** 排在 11/20 10:50。
2. **Given** 優先場與一部層級較高的片衝堂，**When** 排程，**Then** 兩部片都照原本規則排入，理性與感性改排其他場次。
3. **Given** 11/20 標「只看這場」，**When** 排程，**Then** 只會排 11/20；排不進去則未排入，原因為「指定場次都排不進去」。
4. **Given** 同一部片有多場「優先」，**When** 排程，**Then** 挑能讓優先場影片數最多的組合；同分時沿用場次較早。
5. **Given** 一場有優先但沒有 ★、另一場有 ★ 但沒有優先，**When** 排程，**Then** 排優先場（優先場影片數先於 ★）。

**功能需求（FR）**:

- **FR-501**: 選片卡片的展開場次列，每列 MUST 有三態控制「一般｜優先｜只看這場」，預設一般；點選即保存，再點同一態不取消（改點「一般」取消）；同一部片可有多場同一種標記。
- **FR-502**: 控制項高度 MUST ≥ 44px，390px 寬度不得水平捲動。
- **FR-503**: 卡片收合時，有標記的片 MUST 顯示短提示：優先顯示日期（`優先 11/20`），只看顯示日期與時間（`只看 11/20 10:50`），多場以「、」連接。
- **FR-504**: 「只看這場」MUST 為硬限制：該片有任何只看場次時，只有這些場次是該人的候選；沒有可排的只看場次時該片不排入。必看片 MUST 列入未排入清單，原因為「指定場次都排不進去」。
- **FR-505**: 個人排程目標 MUST 依序為：必看數、想看數、有空再看數、層內排序、**排在優先場的影片數**、★ 場次數；優先場 MUST NOT 使任何影片少排或改變層內排序的結果。
- **FR-506**: 標記 MUST 保存在此裝置（`session_marks`，選填）、包含在分享連結；沒有任何標記時 MUST NOT 寫入欄位；`schema_version` 維持 3。
- **FR-507**: 標記改動 MUST 使行程顯示「條件已變更，重新排程」。
- **FR-508**: 行程頁排在優先場的列 MUST 顯示小標「優先場」。
- **FR-509**: 搶票清單的備案 MUST：片有「只看」場次時只含「只看」場次；否則優先場排在備案最前，其餘沿用既有順序；排定場次沿用行程。

### 使用者故事 2 - 兩個人一起看時，知道我犧牲了什麼 (Priority: P1)

作為兩人模式的使用者，我希望預設以「一起看」為優先，但當我的優先場因此被放棄時，工具讓我看到兩種安排各自的代價，由我決定，以便不是默默被換掉場次。

**為何為此優先級**: 兩人模式是主要使用情境；偏好與一起看會直接衝突。

**獨立驗證方式**: 用下例資料排程，行程頁出現理性與感性的取捨卡片，內容與表格一致；按 B 後行程改變；按「改回一起看」還原。

**舉例說明**（姓名為虛構）：

Fischer 與小美都想看理性與感性、北方（皆想看，兩人都有同樣層級）。Fischer 偏好理性與感性 11/20 10:50。

- 理性與感性：11/15 11:00、11/20 10:50（皆 136 分鐘，TITAN）
- 北方：11/15 14:00、11/20 12:00（皆 100 分鐘，TITAN）
- 小美 11/15 14:00 之後沒空、11/20 11:30 之前沒空（所以理性與感性只有 11/15 11:00、北方只有 11/20 12:00 能和她一起看）
- Fischer 全部有空；11/20 10:50 的理性與感性（到 13:06）與 11/20 12:00 的北方衝堂

| | A：一起看（預設） | B：看你的優先場 |
| --- | --- | --- |
| 理性與感性 | 一起看 11/15 11:00 | Fischer 11/20 10:50、小美 11/15 11:00（各自看） |
| 北方 | 一起看 11/20 12:00 | Fischer 11/15 14:00、小美 11/20 12:00（各自看） |
| 放棄 | Fischer 的優先場 11/20 10:50 | 兩部片都不再一起看 |

取捨卡片的差異行：「《理性與感性》不再一起看」「《北方》不再一起看」。

**驗收情境**:

1. **Given** 上例，**When** 排程，**Then** 預設為 A（理性與感性 11/15 11:00、北方 11/20 12:00，兩部都一起看）；行程頁出現一張理性與感性的取捨卡片，A 顯示「一起看 11/15 11:00」並註明放棄「Fischer 的優先場 11/20 10:50」，B 顯示「看你的優先場 11/20 10:50」並列出差異「《理性與感性》不再一起看」「《北方》不再一起看」。
2. **Given** 上例，**When** 按 B，**Then** 行程改為 Fischer 11/20 10:50 看理性與感性、北方 11/15 14:00，小美 11/15 11:00 看理性與感性、11/20 12:00 看北方（全部各自看）；決定保存為 Fischer 的 `pinned_choices`；卡片仍在，選中 B 並出現「改回一起看」。
3. **Given** 已選 B，**When** 按「改回一起看」，**Then** 行程回到預設，決定被移除。
4. **Given** 兩個選項實際沒有差異（優先場本來就是一起看的場次，或不一起看也排得到），**When** 開啟行程頁，**Then** 沒有取捨卡片。
5. **Given** 個人模式，**When** 開啟行程頁，**Then** 沒有取捨卡片。
6. **Given** 已選 B，**When** 產生分享連結並在另一台開啟，**Then** 標記與決定都帶過去，行程相同。
7. **Given** 同伴小美自己的優先場被一起看犧牲，**When** 開啟行程頁，**Then** 同樣出現卡片（B 寫「看小美的優先場」），可替小美按 B（決定存在小美的資料裡）。

**功能需求（FR）**:

- **FR-510**: 兩人排程目標 MUST 依序為：各人個人最佳（層級數、層內名次）、一起看場次數、**優先場影片數（兩人合計）**、★ 場次數。
- **FR-511**: 同伴的場次標記 MUST 隨個人分享連結「當作同伴加入」帶入 partner 並用於排程；合併結果連結整份 `UserState` 帶走。
- **FR-512**: 取捨卡片出現條件 MUST 同時成立：該人對這部片有「優先」標記（且沒有「只看」）；預設排程（不含該片的取捨決定）中該人這部片的場次不是優先場；把該人這部片鎖定在優先場重跑後，該片排在優先場、該人的影片集合不變，且「一起看」的片集合改變。
- **FR-513**: 取捨卡片 MUST 顯示：選項 A（一起看的場次或目前場次、放棄的優先場）、選項 B（優先場場次與差異清單）。差異清單以人話列出兩人相對 A 的具體變化：哪些片不再一起看／改成一起看、哪些片換場次、哪些片少看或多看（含層級）、★ 場次變化，最多 6 行，超過以「還有 n 項」收尾。
- **FR-514**: 取捨計算 MUST 以實際重跑排程為準；每個衝突片只重跑一次（已選 B 的片，預設選項重跑一次）；衝突片數超過 8 時只處理影片順序最前的 8 部。
- **FR-515**: 使用者按 B MUST 把「片 × 人」的決定寫入該人的 `pinned_choices`（自己寫 `UserState`、同伴寫 `PartnerData`），立即重新排程；「改回一起看」MUST 移除該決定。決定 MUST 使該片的候選場次限定在該人的優先場（效果等同只看這場）。
- **FR-516**: 取捨決定 MUST 保存在此裝置並包含在分享連結；移除同伴時 MUST 清除自己的 `pinned_choices`；沒有優先標記的片，既有決定不生效。
- **FR-517**: 個人模式 MUST NOT 顯示取捨卡片，行為只受 FR-505 影響。

### 邊界情況

- 「只看」的場次本人沒空／被標沒搶到：該片視為排不進去（原因「指定場次都排不進去」），不改用其他場次。
- 優先場與已搶到（固定）的場次不同：已搶到者優先，優先標記不影響。
- 一片同時有「優先」與「只看」標記：以「只看」為準，優先標記保留但不生效。
- 場次表更新後標記的場次消失：標記保留於本機，排程時忽略。
- 取消所有標記：欄位移除。

## 需求 *(必填)*

### 全域需求

- **NFR-501**: 加入優先場影片數後，50 部已分層影片（每部 3 個場次、每部頭尾場次都標優先）的個人排程 MUST 仍滿足 001 NFR-001（10 秒內、相同輸入相同結果）；兩人模式以 30 部驗收，取捨計算（最多 8 個衝突片各重跑一次）MUST 不使行程頁等待超過 10 秒。有優先場候選時場次指派改用較小的決定性節點預算（300,000），其餘維持原預算。
- **FR-518**: 沒有任何標記與決定時，所有既有行為 MUST 與 004 相同（既有 Example 全數通過）。

#### 狀態與公式

```
標記(人, s) ∈ { 一般, 優先, 只看 }
受限(人, 片) ⇔ 該片有任何場次標「只看」 ∨ (已選 B(人, 片) ∧ 該片有任何場次標「優先」)
候選(人, 片) = { s | 可看(人, s) ∧ (¬受限 ∨ (有只看 ? 標記=只看 : 標記=優先)) }
優先數(人) = | { 片 | 該人排入的 s 標記 = 優先 } |

個人目標 = (必看數, 想看數, 有空再看數, 層內名次, 優先數, ★ 數)       字典序，越大越好
兩人目標 = (各人個人最佳, 一起看數, 優先數(自己)+優先數(同伴), ★ 合計)  字典序

取捨(人 P, 片 F) 成立 ⇔
  A = 排程(不含 F 的取捨決定)；B = 排程(P 的 F 鎖定在優先場)
  ∧ A 中 P 的 F 不是優先場 ∧ B 中 P 的 F 是優先場
  ∧ 影片集合(P, A) = 影片集合(P, B) ∧ 一起看片集合(A) ≠ 一起看片集合(B)
```

### 關鍵實體

- **場次標記**（session_marks）：session_id → `prefer`／`only`。
- **取捨決定**（pinned_choices）：film_id → `prefer_session`。
- **取捨**（衍生，不保存）：人、片、選項 A、選項 B、差異清單。
