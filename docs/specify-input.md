我想從零建立一個「2026 台北金馬影展 選片排程輔助工具」，給我和女友兩個人一起用。

背景：
- 單場預售票 2026/10/25（日）13:00 在拓元開賣，影展 11/6 起。熱門場次開賣即秒殺。
- 每次選片、看場次、避免衝堂都要搞到頭昏腦脹，想要工具幫忙排出最適合的片單與場次。
- 場次資料來自金馬官網場次表（https://www.goldenhorse.org.tw/film/programme/schedule/），按日期分頁，
  每筆有：開演時間、片名、片長（分）、分級、影廳（如「台北信義威秀 10廳」「TITAN」），
  以及標記 ★（影人出席）、◆（華語無中英字幕）、▲（非英語無英文字幕）、⊚（非售票活動）。

需求：
- 我和女友各自輸入「可以看 / 不可以看」電影的時段。
- 我們各自排好想看的片單與優先順序（例如 必看 / 想看 / 有空再看，分層或排序都可，先試試看）。
- 工具把兩人的條件合併，排出兩人「一起看」的最佳片單與場次組合（每部片只看一場）。
- 衝堂規則：
  - 同一影城不同廳（例如信義威秀 10 廳 → 13 廳）：前一場結束到下一場開演至少 5 分鐘。
  - 跨影城（信義威秀 ↔ 松仁威秀）：至少 15 分鐘。
  - 其他影城組合（如 TITAN）規則待確認。
  - 一天最多看幾部：之前沒處理過，需要討論。
- 偏好：同一部片有多個場次時，影人出席（★）的場次優先。
- 價格（日場 / 一般票價）不在本需求的評估維度。
- 產出：
  - 建議片單與場次（依日期排列的行程）。
  - 搶票用的優先順序清單（熱門 / 高優先先搶），以及每部片的備案場次，搶不到時可以快速切換。
- 兩個人要能分別在自己的手機或電腦上操作。
